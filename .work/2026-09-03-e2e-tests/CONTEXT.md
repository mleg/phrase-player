# Phrase Player

Phrase Player helps a language learner listen to local audio one subtitle phrase at a time. The learner's media stays in the browser.

## Language

**Media pair**:
An audio file and an SRT subtitle file with the same base name in the same selected folder.
_Avoid_: File pair, track

**Phrase**:
One timed subtitle entry that defines the text and playback interval presented to the learner.
_Avoid_: Caption, line

**After-phrase mode**:
The learner's choice to stop, repeat, or continue after the current phrase ends.
_Avoid_: Playback policy, action
